# 舞蹈老师 Web v1.2.0 发布记录

发布日期：2026-08-29

## 新增

- 对照录制前增加“录制镜像”，镜像状态在开始时锁定并真正写入下载视频。
- 录制回看增加独立“回看镜像”，可随时翻转回看画面，同时明示下载文件的录制镜像状态。
- 对照 Canvas 左上角直接绘制当前 1–8 拍数与拍点，录制现场和下载视频都保留。
- 口令由系统 Web Speech 改为可替换的 8 个本地 WAV 短采样，为后续换成用户本人声音留好唯一入口。
- 老师原声和已开启口令通过 Web Audio 混成一条音轨，与 Canvas 视频一起写入下载文件。

## 稳定性约束

- 录制期间的拍数、口令和老师原声共用老师播放器的时间线，六档循环的跳回不被对照模式接管。
- 口令同时连接扬声器与录制总线，避免“现场听到、文件没有”的两套逻辑。
- 录制时使用开始瞬间的镜像快照，其他界面状态变化不会在文件中造成半途翻转。
- 音频获取失败时仍允许录制视频，不让可选音频能力阻断核心录像。

## 验证

- 新增 Canvas 拍数、单音轨混音、录制/回看镜像回归测试。
- 前端 32 个测试文件、230 项测试全部通过；TypeScript 与生产构建通过。
- 后端 66 项测试通过；Docker 单容器重建、`/health`、OpenAPI 版本与 8 个口令资源检查通过。
