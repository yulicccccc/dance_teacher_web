# 舞蹈老师 Web v1.0.1 发布记录

> 日期：2026-08-09
>
> 目的：让公网视频播放达到本地版的即时可用体验。

## 修复

- 上传的 MP4/MOV 在分析阶段用 ffmpeg `-c copy -movflags +faststart` 无损重封装。
- 只把 `moov` 容器索引移动到文件开头，不重新编码视频或音频，不改变画质。
- 视频 API 不再发送 `Content-Disposition: attachment`，而是作为浏览器媒体源内联提供。

## 根因

iPhone MOV 常把 `moov` 索引放在整个媒体数据之后。真实验收文件的索引位于约 86.8 MB，导致公网浏览器必须读取接近整个文件后才能显示时长；本地磁盘足够快，所以本地测试不明显。

## 验收

- 后端单元测试覆盖 `moov < mdat` 和 pipeline 使用新路径。
- 重新部署后用同一真实 MOV 核对播放器元数据、118.01 BPM、11 小节及循环。
