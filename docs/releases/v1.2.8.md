# 舞蹈老师 Web v1.2.8 发布记录

发布日期：2026-08-30

## 三音色重音节拍器

- 控制栏新增“节拍器”，提供“清脆 / 木鱼 / 电子”三种本地合成音色。
- 每个 8 拍的第 1 拍使用更高、更响的重音，便于同时判断细拍是否对齐、小节第一拍是否正确。
- 独立音量为 0–200%，默认 80%；不改变老师原声或口令，并按课程保存。
- 节拍器直接由现有 `beatIndex` 触发，不建立第二套计时器，所以慢放、seek、逐拍、六档循环和偏移重算后仍使用同一拍网格。
- 合成音同时进入扬声器和既有对照录制混音总线；录制现场与下载录像保持一致。
- 播放器聚焦时可用 Shift+`C` 开关节拍器；原 `C` 继续只控制口令。

## Tap BPM

- 节拍信息卡新增“跟拍点按 BPM”。听着音乐每拍点一下，至少 4 次后自动填入 BPM 输入框。
- 使用最近最多 9 次有效间隔的中位数，单次抢拍或拖拍不会主导结果。
- 有效范围 40–300 BPM；停顿超过 2 秒自动开始新一轮。
- 点按结果不会偷偷改课程，仍需用户点击“用此 BPM 重算”，继续复用已验证的固定 BPM 后端链路。
- 页面明确提示：越播越偏通常是 BPM 问题；始终固定错同样拍数通常是第一拍相位问题。
