## 完整扒舞键盘模式

播放器获得焦点后可使用以下快捷键；输入框、按钮等子控件不会触发，Cmd/Ctrl/Alt 组合键继续交给浏览器和系统。

| 功能 | 快捷键 |
|---|---|
| 播放/暂停 | Space、Enter、K |
| 前一拍/后一拍（暂停定格） | `,` / `.`、← / → |
| 上一小节/下一小节 | Shift+← / Shift+→、`[` / `]` |
| 减速/加速 0.05× | Shift+`,` / Shift+`.`、`-` / `+` |
| 恢复 1× | `0` |
| 循环总开关 | `R` |
| 当前/前节/后节/单节/多节/AB | `1` / `2` / `3` / `4` / `5` / `6` |
| 设置 A/设置 B/清除 AB | `A` / `B` / `X` |
| 视频镜面/拍点镜面 | `M` / Shift+`M` |
| 口令 | `C` |
| 当前小节已学会 | `D` |
| 全屏 | `F` |
| 完整快捷键表 | `?` |

逐拍、逐节和调速允许长按；开关、模式与标记类操作忽略长按重复，防止状态反复闪烁。中文输入法通过物理键位识别逗号、句号、方括号和数字键。
