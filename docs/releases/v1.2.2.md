# 舞蹈老师 Web v1.2.2 发布记录

发布日期：2026-08-29

## BPM 节奏层修复

- 自动检测从单一 120 BPM 先验改为 120 / 180 双候选，比较真实 onset 支持与全曲拍间稳定性，避免密集打击乐把结果吸到错误的非二倍节奏层。
- 当稳定快候选与原候选不是 1×/2× 关系时，自动选择快候选中更强的半速相位作为舞蹈 8 拍网格；明确的快歌与普通 120/130 BPM 素材保持原行为。
- 人工 BPM、第一拍调整、六档循环、数拍、口令和对照录制仍读取同一份最终拍点网格，不增加联网依赖。

## 真实回归

- 用户课程 `eeb64202-45ea-4952-bf05-e02c6ecc8a12`（Tyla - THAT GIRL，89.93 秒）：旧版 126.05 BPM / 190 拍 / 0.755 置信度；新版 89.10 BPM / 134 拍 / 0.926 置信度。
