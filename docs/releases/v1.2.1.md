# 舞蹈老师 Web v1.2.1 发布记录

发布日期：2026-08-29

## 口令替换

- 把用户录制的 `Stream Bend Way.m4a` 识别并切分为“一”到“八”八个正式口令。
- 每段保留 40–50 ms 左右的首尾缓冲，并使用 8–12 ms 淡入淡出，防止切掉辅音或产生点击声。
- 不对极短口令使用不稳定的动态响度推测；根据每段实测平均音量单独补偿，八段成品均为 -20.0 dB，峰值为 -9.5 至 -5.4 dB，无削波。
- 统一转为 24 kHz、单声道、16-bit PCM WAV；日常学习、对照录制现场和下载视频自动共用。
- 新增 `manifest.json` 和资产测试，锁定源文件、8 个拍号、WAV 格式、时长及 SHA-256，防止未来打包丢失或顺序错位。

## 验证

- 录音转写结果为“一 二 三 四 五 六 七 八”，8 个安静间隔可稳定切分。
- 前端 33 个测试文件、231 项测试通过；TypeScript 与生产构建通过。
- 后端 66 项测试通过；Docker 重建后 OpenAPI 版本为 1.2.1，8 个新 WAV 的线上服务校验值与 manifest 一致。
