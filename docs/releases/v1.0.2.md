# 舞蹈老师 Web v1.0.2 发布记录

发布日期：2026-08-28

## 修复

- 修复线上 BPM 分析到 50% 附近偶发 `Request failed with status code 429`。
- 状态轮询从固定 `setInterval` 改为上一请求完成后才安排下一次，彻底禁止慢请求重叠。
- 正常轮询间隔由 1 秒调整为 2 秒，降低免费托管边缘层压力。
- 遇到 429、408、网络中断或 5xx 时自动退避并继续分析；429 从 15 秒开始退避，最长 30 秒。
- 临时限流不再显示为红色失败，而提示“正在自动等待并继续分析”，用户无需重新上传。
- 404 等不可恢复错误会停止轮询并显示后端的可读错误，避免无限请求。

## 证据

- 故障响应由 Render 前方 Cloudflare 返回，包含 `cf-mitigated: challenge`，并未到达 FastAPI。
- 新增 3 项回归测试：慢请求不重叠、429 自动退避、完成后停止轮询。
- 前端完整测试 210 项全部通过，生产构建通过。
