# 舞蹈老师 Web v1.3.0 发布记录

发布日期：2026-09-07

## 舞蹈 BPM 防误倍速

- 修复真实 118 BPM 课程因切分低音而被错误提升到 234.91 BPM 的问题；同一素材现在输出约 117.45 BPM。
- 低频中点证据继续用于发现密集节奏层，但超过 200 BPM 的候选默认按每隔一拍生成可练的舞蹈计数网格。需要听到细分时继续使用“快拍 2×”，不牺牲节拍器能力。
- 当算法确实发现可信的 >200 BPM 声学层、却选择半速舞蹈网格时，置信度封顶 0.49，主动提示用户试听，不再对节奏层歧义给出虚假的高置信。
- 显示 BPM 仍严格由最终拍点的中位间隔反推，保持 `BPM = 60 / median(diff(beats))`。

## 一键试听半速/倍速

- 节拍信息卡会列出 40–300 范围内的半速和倍速候选，例如 118 BPM 可直接尝试 59 或 236。
- 点击候选复用已经验证的固定 BPM 重算 API；小节、数拍、六档循环和 AB 都从同一新网格重建，不产生旁路状态。
- BPM 重算返回后输入框会同步最新结果，避免仍显示旧检测值。

## 真实课程回归

- 新增 `backend/scripts/real_bpm_regression.py`，以 SHA-256 匹配本机 gitignored WAV；用户视频和音频不会写入仓库或上传。
- 当前 5 条唯一真实课程全部通过 3% 舞蹈 BPM、6% 拍点数和 BPM/网格一致性护栏。
- 对照另一个纯前端频谱通量/Viterbi 项目后，没有直接移植其检测器：它的 281 项合成 smoke 全绿，但在本项目 5 条真实课程上为 0/5。其真实音乐验收思想被吸收，算法本身没有冒险替换。
- 轻量 HPSS 鼓声轨也做过同批候选探测；结果与混音候选几乎完全相同，暂不把额外计算塞入主流程。后续只有在更广真实样本证明增益后才加入。
