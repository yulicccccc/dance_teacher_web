# 舞蹈老师 Web v1.1.0 发布记录

发布日期：2026-08-29

## 新增

- 循环模式由三档扩展为六档，排列为“当前 / 前节 / 后节 / 单节 / 多节 / AB”。
- “当前”锁定播放头所在动作，循环上一拍、当前拍和下一拍，共三拍。
- “前节”练当前小节 1–4 拍，同时带入上一节第 8 拍与当前第 5 拍作为衔接。
- “后节”练当前小节 5–8 拍，同时带入当前第 4 拍与下一节第 1 拍作为衔接。
- 左栏在前节、后节和单节模式显示真实循环起止秒数。
- 新三档模式与循环开关、次数等一起保存，刷新或重开课程后恢复。

## 稳定性约束

- 六档循环复用同一个 `requestAnimationFrame` 引擎和程序 seek guard，没有新增互相竞争的第二套播放器逻辑。
- “当前”只会在真实用户拖动、逐拍或列表跳转时重锁动作；自动回跳不会把目标换掉。
- 在前节、后节和单节之间切换时保留用户明确选中的小节，即使播放头正在相邻上下文拍里也不会串节。
- 首节、末节与偏移后的残缺小节统一按 0 秒/媒体结尾截断，不制造越界范围。
- 对照录制继续使用同一个老师视频，开始录制不会关闭任何循环模式。

## 验证

- 新增纯计算、真实引擎回跳、模式切换、列表秒数、状态持久化、控制栏顺序及六档对照录制回归测试。
- 前端 33 个测试文件、234 项测试全部通过；TypeScript 与生产构建通过。
- 后端 66 项测试通过；Docker 单容器重建和 `/health` 检查通过。
