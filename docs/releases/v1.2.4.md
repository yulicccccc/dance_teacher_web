# 舞蹈老师 Web v1.2.4 发布记录

发布日期：2026-08-29

## 双击始终打开当前版本

- 一键启动器不再把“容器健康”误认为“版本正确”：它会比较项目 `VERSION` 与运行中健康接口返回的版本。
- 运行版本落后或没有版本标识时，双击 App 会自动重建并等待新容器健康，不需要用户打开终端。
- 浏览器使用带当前版本参数的本地地址打开，使新发布第一次启动一定重新取得页面入口。

## 缓存边界

- React 的 `index.html`、课程深链接和可替换的非指纹文件返回 `Cache-Control: no-store, max-age=0`，不再留下旧页面外壳或旧口令资源。
- Vite 生成的带内容指纹 `/assets/` 文件仍可长期缓存；文件内容一变，文件名随之改变，不影响更新正确性。

## 验证

- 回归测试覆盖主页与课程深链接的禁止缓存响应头。
- 启动脚本语法检查通过；前端 33 个测试文件、234 项测试和后端 69 项测试通过。
- 前端生产构建与 Docker 多阶段构建通过。
- 真实演练从健康的 v1.2.3 容器自动识别版本不符并升级至 v1.2.4；随后再次启动约 1 秒完成且不重复构建。
- 容器完全停止后，一键启动也能恢复 v1.2.4、复核版本并正常打开；若磁盘镜像为旧版，同一路径会在打开前自动重建。
- 本地 `/health` 返回 v1.2.4；主页和既有课程深链接均为 200，并返回 `Cache-Control: no-store, max-age=0`。
