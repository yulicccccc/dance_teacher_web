# 舞蹈老师 Web v1.2.5 发布记录

发布日期：2026-08-29

## 回看镜像只翻录像画面

- 修复“回看镜像”把原生播放器控制层也一起翻转的问题。
- 录像画面仍按用户选择水平镜像；播放按钮、时间轴、时间文字、音量、全屏和菜单通过控件层反向抵消，保持正常方向与位置。
- 只处理录制完成后的回看视图，不改变录制镜像、已经生成的下载文件或普通教学播放器。

## 一键更新边界

- 双击 App 会自动运行这台 Mac 项目中已经保存的最新版本，并在本地容器落后时自动重建。
- 启动器不会自行从 GitHub 或互联网下载尚未同步到本机项目的新代码。

## 验证

- 组件回归覆盖回看镜像样式只在开关开启时生效。
- 前端 33 个测试文件、234 项测试和后端 69 项测试通过；生产构建通过。
- 真实 Chromium 视觉验收：画面保持水平镜像；播放/时间在左，音量/全屏/菜单在右，时间文字方向正常。
- 一键启动器真实识别运行中的 v1.2.4 并自动构建、切换到健康的 v1.2.5。
