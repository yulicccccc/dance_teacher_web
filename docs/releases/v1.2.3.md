# 舞蹈老师 Web v1.2.3 发布记录

发布日期：2026-08-29

## 独立口令音量

- 开启“口令”后显示独立音量滑杆，可在 0–200% 之间调节，默认 100%。
- 该滑杆只改变用户“一”到“八”的口令声，不改变老师视频原声。
- 音量按课程保存，刷新或重新打开课程后继续使用上次设置；旧课程自动采用 100%。

## 学习与录像一致

- 每个口令采样在分流前只经过一个共享 Web Audio `GainNode`。
- 调节后的同一份声音同时送往扬声器和对照录像混音总线，因此学习、录制现场和下载视频不会出现两套音量。
- 音量调整不改变既有口令开关、循环、拍点、老师原声或录像镜像行为。
