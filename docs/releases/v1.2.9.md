# 舞蹈老师 Web v1.2.9 发布记录

发布日期：2026-08-30

## 节拍器三档速度

- 节拍器新增“慢拍 ½× / 正常 1× / 快拍 2×”，默认继续使用正常档，旧课程无感迁移。
- 慢拍只在舞蹈数拍 1、3、5、7 发声，适合检测 BPM 是舞蹈大拍两倍时使用。
- 正常档保持每拍一次，行为与 v1.2.8 完全相同。
- 快拍在每个真实拍点中间补一次普通音，适合检测 BPM 只有舞蹈细拍一半时使用；补音永远不冒充每小节第 1 拍重音。
- 速度档与音色、音量一起按课程保存，只改变听到的提示密度，不重新计算 BPM、小节、拍点偏移或任何循环范围。

## 同步策略

- 慢拍和正常档继续复用播放器的 `beatIndex`。
- 快拍不使用 `setTimeout` 或独立节拍器时钟；它由 `requestAnimationFrame` 观察视频媒体时间是否穿过相邻真实拍点的中点。
- 因此播放变速、暂停恢复、拖动、逐拍、拍点偏移和六档循环回跳不会造成节拍器自身漂移；现场和对照录制继续使用同一音频混音总线。
