# 舞蹈老师 Web v1.3.1 发布记录

发布日期：2026-09-27

## Mac / iPhone 多摄像头选择

- 对照练习在取得摄像头权限后枚举全部视频输入，提供“系统默认摄像头”、Mac 内置摄像头、iPhone 连续互通相机及其他外接摄像头的选择器。
- 选择新设备时使用精确 `deviceId`；新流成功挂载后才停止旧流，因此 iPhone 忙碌或切换失败不会把仍可用的预览弄黑。
- 上次成功选择保存在本机；重新进入对照练习会优先恢复。保存的设备失效，或 iPhone 在练习中断开时，会清除旧选择并回退系统默认。
- 支持浏览器 `devicechange` 自动刷新，也提供“刷新摄像头”按钮；录制中锁定选择，防止录像中途出现黑帧。
- 快速连续切换或退出时用请求序号淘汰迟到的摄像头流，并立即停止其 tracks，避免旧请求覆盖新选择或让摄像头灯常亮。
- 如果默认镜头被 Photo Booth、会议软件或其他进程占用，错误页仍会列出可见摄像头并提供“重试此摄像头”，可直接改选 iPhone。

## 逐拍快捷键

- `,` / `.` 与左/右方向键会记住按键前的播放状态：原本播放就从目标拍继续播放，原本暂停就保持暂停。
- 双击画面左右两侧仍保留“跳一拍并定格”，方便逐帧看动作；两套交互都继续走原来的循环重锁逻辑。

## 对照性能

- 双视频 Canvas 的重型绘制从显示器 60Hz 限制到 30fps，与录像 `captureStream(30)` 对齐，不再计算不会写入录像的重复帧。
- Continuity Camera 以 960×540 / 30fps 为理想输入，足够填满录像右半边，同时降低无线传输、解码与缩放压力。
- MediaRecorder 改为优先 VP8+Opus，VP9 作为回退，更适合本机 Intel Mac 的实时双视频编码。
- 录制计时界面由 10Hz 降到 5Hz；每次停止录制都释放 Canvas 捕获视频轨和老师音频捕获流，连续重录不会累积隐藏编码任务。
- 录制启动增加单操作锁与生命周期序号：快速双击只启动一次；音频初始化时退出会回收迟到资源；退出后迟到的 `MediaRecorder.onstop` 不再创建无用 Blob 或更新已卸载界面；停止后迟到的 `video.play()` 也不会补建计时器。

## 不变量

- 只替换右侧学习者视频的 `srcObject`；老师视频仍由原六档循环引擎驱动。
- Canvas 对照录像、录制镜像、回看镜像、拍点、本人 1–8 口令、节拍器和老师原声混音链路均保持原实现。
- 无需后端或系统插件；只要 macOS 已将连续互通相机暴露给浏览器，它就会出现在选择器中。
