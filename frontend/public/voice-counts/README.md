# 自定义 1–8 口令

应用会加载本目录中的 `1.wav` 到 `8.wav`。这 8 个文件同时用于日常练习、对照录制现场和下载的对照视频，所以只需替换一次。

当前正式口令来自用户录音 `Stream Bend Way.m4a`，已切成 8 段、统一到平均 -20 dB，并转为 24 kHz 单声道 16-bit PCM WAV。切分边界、增益和文件校验值记录在 `manifest.json`。

推荐原始录音格式：

- 一条 WAV 或 M4A 音频，从 1 说到 8。
- 开头、结尾各留 1–2 秒安静，每个数字之间留约 1 秒。
- 每个数字音量和距离一致，干脆、自然，不要配乐或混响。

导入时将连续录音切成 8 个短片段，统一转为 24 kHz、单声道 PCM WAV，并保持每个片段尽量不超过 0.5 秒。
